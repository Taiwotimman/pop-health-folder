# 🏥 Population Health Readmission Risk Intelligence Platform

An end-to-end healthcare analytics solution built to identify hospital readmission risk, uncover health inequities, and support better population health decisions using SQL, Python, predictive modelling, and interactive dashboards.

## 📌 Project Overview

Hospital readmissions remain a major challenge, increasing healthcare costs and negatively affecting patient outcomes.

This project demonstrates how healthcare organizations can use analytics to proactively identify high-risk patients, optimize interventions, and improve care delivery.

The platform combines:

- SQL data querying & transformation  
- Python analytics workflows  
- Predictive risk modelling  
- Health equity insights  
- Social Determinants of Health (SDOH) analysis  
- Interactive executive dashboards
